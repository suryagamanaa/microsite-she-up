# SHE-aga Microsite

A website that brings financial education and current financial news together in one place, connected to a WhatsApp community and a guide for activating Astra insurance.

**Live site:** https://microsite-she-up.vercel.app
(Verify this address before publishing. The link originally noted for this project read `vercell.app`, which is not Vercel's domain.)

The microsite is part of **SHE-UP! (Sinergi Hidup Ekonomi Perempuan)**, a financial literacy program by team TRIHAS (IPB University), supported by Astra through the ACTION! program. It acts as the place where learning from the board game continues, since the game's QR codes lead here.

## What it does

- **Financial education:** short, practical content on managing money, risk, and protection.
- **Current news:** financial news so users stay informed beyond the program.
- **Community:** a link to the WhatsApp community, so action taken together feels safe and normal.
- **Insurance guide:** step-by-step guidance for activating Astra insurance.
- **QR entry point:** reachable from the SHE-aga board game and from event materials.

## Who it is for

- Ibu-ibu (25-70 years), including micro-business owners who mix business and personal money.
- Mahasiswi (18-25 years), who already use e-wallets and paylater and want practical habits.
